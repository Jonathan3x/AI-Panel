# IA PANEL - HTML & CSS Project [EN]

This is a personal project to show what I've learned so far in HTML and CSS. I applied `flexbox` and `media queries` to create a layout that works well on both mobile and desktop screens.

The panel shows three products with images, descriptions, prices, and a call-to-action button.

---

## 📌 Why did I build this?

I wanted to apply everything I've learned so far in a practical way. It helps me review what I know and have a project to include in my GitHub portfolio.

---

## 🖼️ Preview

- 📱 Responsive design using Flexbox and Media Queries  
- 💻 On large screens, the panels are side by side  
- 📱 On mobile, they are stacked vertically

---

## 🛠️ Knowledge Applied

- Basic HTML (structure, tags, lists, links, images)
- CSS (colors, fonts, spacing, borders)
- Flexbox (layout and alignment)
- Media Queries (responsive design)
- Google Fonts
- Pseudo-classes (`:hover`, `:focus`)
- Responsive Design

---

## 🚀 What’s next?

Keep learning about CSS Grid and JavaScript to add more interactivity to future projects.
